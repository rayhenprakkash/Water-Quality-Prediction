📘 About This App

The Water Quality Prediction System is a machine learning based web application designed to predict the quality of water by analyzing important water parameters. The system helps determine whether water is safe or unsafe for drinking and other purposes, enabling early detection of water pollution and supporting environmental monitoring.

This web app is designed for predicting water pollutant levels using Machine Learning.

Features:
Predict pollutants based on year, station ID, and water quality parameters
User-friendly Streamlit UI
Interactive charts and tables
Works in Random Mode without a trained model
👨‍💻 Built with Python, Streamlit, Pandas, and Joblib

Technologies Used:
Python 3.12
Pandas, NumPy – Data handling
Scikit-learn – Machine learning model and evaluation
Matplotlib, Seaborn – Data visualization
Jupyter Notebook – Interactive experimentation


Model Performance:
The model was evaluated using:
R² Score
Mean Squared Error (MSE)
Performance was acceptable across all parameters
